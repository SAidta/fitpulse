# FitPulse

FitPulse is a lightweight Progressive Web App (PWA) designed to help users stay consistent with their fitness journey by combining workout routines, nutrition guidance, and home workout planning in one easy-to-use platform.

## Features

- 🏋️ Home workout routines
- 🍎 Basic nutrition guidance
- 📅 Daily fitness planning
- 📱 Mobile-friendly responsive design
- ⚡ Progressive Web App (PWA) support
- 🔄 Offline access through Service Worker
- 🖥️ Installable on desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Progressive Web App (PWA)
  - Service Worker
  - Web App Manifest
